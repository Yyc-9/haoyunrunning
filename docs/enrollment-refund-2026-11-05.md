# 退費退班功能

后台课程报名详情原有转班区域现为「轉班／退費退班」。打开「設定轉班／退費」后，已确认入账的有效报名可选择「登記退費退班」。预览姓名、原班和原收款金额，填写原因并勾选退费已另行办理，才能确认退出该班。

确认只将该笔报名的registration_status设为cancelled，名额统计排除该报名；保留账号、原收款状态/金额和出席历史，也不改变其他班报名。独立审计表保存原报名快照、操作者、原因与时间。此功能登记线下已处理的退费，不执行退款转账，也不自动计算财务净收入。

接口仅允许当前超级管理员调用，数据库再次验证角色、有效已入账报名及进行中/招生中季度。预览不写入，确认核对预览指纹，记录变化时必须重新预览；事务内保存审计与退出状态。已退班记录无法由同步重新改为有效。重复确认不会重复释放名额。

验证：338项测试通过；新增数据库回归在本机PGlite执行，覆盖授权、只读预览、过期预览、封存/未核款拒绝、仅释放一席、收款保留、其他班不变、审计、重复提交与同步保护。修改文件ESLint及生产构建通过。构建外部sitemap ECONNRESET警告沿用原记录。

实际组件WebKit预览验证390px与1440px宽度无横向溢出；空原因/未确认时提交禁用；模拟失败重新预览保留原因并重新要求勾选；成功显示释放名额并调用名册刷新。截图和虚构接口夹具留output/playwright，不纳入发布。

用户明确只添加功能，不操作真实学生；本次未为任何真实报名执行退班。
