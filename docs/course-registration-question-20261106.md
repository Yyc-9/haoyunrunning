# 課程報名自訂下拉題

適用需求：2026Q4好運跑班X混合訓練（2026-Q4，課程代碼 `zhubei-night-run-monday-3`）在最後報名步驟的備註上方顯示一個管理員設定的下拉題。

## 管理員操作

1. 進入季度／課程管理的「課程資料」，選擇 2026Q4 與「2026Q4好運跑班X混合訓練」。
2. 找到「報名自訂下拉題」，勾選「啟用報名下拉題」。
3. 填寫題目，選項每行一個，並選擇是否必填。題目最多200字；選項1至30個，每個最多120字，不可空白或重複。
4. 按「儲存並發布至課程與日程表」。學員在「匯款與發票」步驟、備註上方看到該題。
5. 在後台報名詳情查看學員選擇。日後改題目或停用，不會覆寫舊報名的題目和答案。

部署程式不會替管理員設定真實題目或選項。既有課程預設不啟用；只有管理員啟用並發布的課程會顯示。

## 資料及驗證

- 設定存於現有季度課程 `course_data.registrationQuestion`；答案快照存於 `signup_leads.payload.registrationQuestionAnswer`，不需資料庫遷移。
- 前後端驗證必填及有效選項。題目、選項或必填設定在學員填寫期間變動時，伺服器要求重新整理，避免舊答案對應新題目。
- 原有管理員權限、報名身分、名額、報價、付款與同意條款檢查保持有效。
- 344 項自動測試通過，含實際報名接口的合法答案儲存、無效答案拒絕及課程資料映射；所有修改檔 ESLint 通過。
- WebKit 本機使用真實表單元件與模擬 API 驗收：390px 手機及1440px桌面、管理員題目預覽、備註上方位置、漏填阻擋、返回上一步保留選項、送出含答案與題目版本。
- 測試未修改正式課程內容，未新增真實報名或匯款資料。
