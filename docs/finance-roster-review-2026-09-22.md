# 財務報名工作區整合

## 已實作

- 本季報名繳費一覽可展開查看報名信箱、電話、該次報名的發票方式、載具或發票信箱、統編與抬頭、報名備註、匯款日期、回報及核對時間、核對備註。
- 不回傳整份報名 payload；只抽取財務所需的三個開票欄位，不讀取學員後來修改的個人開票設定。
- 已解鎖且獲授權的財務帳號可在一覽人工確認入帳，不必先匯入銀行檔案。需勾選核實實收並填寫核對依據。
- 沿用 approve_course_enrollment 加鎖與名額檢查。記錄操作人、核對依據及 reviewed_at；已入帳再次送出不重複修改。封存季度拒絕修改。
- 補件表單、內部備註、歷史紀錄與重試寄送整合進一覽。舊通知頁保留查閱及帶季度、報名定位的跳轉，不再提供處理按鈕。
- 原銀行檔案匯入、選擇匹配及批次確認維持原功能。手機採兩欄摘要、單欄詳情表單。

## 驗證

- 205 項 Node 回歸測試通過。
- 新增接口測試涵蓋無銀行批次人工入帳、重複提交、操作人與依據保存、401/403、確認勾選缺失、封存、滿班、找不到報名及資料最小化。
- TypeScript、受影響檔案 ESLint、正式構建及 diff 格式檢查通過。
- 隔離瀏覽器 1440px/390px 模擬報名：查看開票資料、發送補件、人工入帳、確認後按鈕消失、舊通知頁只跳轉、手機表單寬度與全頁無水平溢出。
- 瀏覽器測試腳本：scripts/verify-finance-roster-ui.mjs；所有 API 及身分均為合成資料，禁止外部網路請求，未寄送真實郵件、未更改真實帳款。

## 交付邊界

本輪為本地實作及驗證，尚未提交或推送，也未以真實財務帳號在正式網站確認款項。部署後應由財務核對實際銀行記錄，再操作真實入帳。
