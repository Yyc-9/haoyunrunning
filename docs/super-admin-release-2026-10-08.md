# 超級管理員管理功能發布說明

2026-10-08｜本地驗證完成，尚未發布。

## 可供發布的結果

相同 `admin` 角色使用相同管理權限。管理員不必請站主直接改資料庫，即可從電腦或手機後台完成以下操作：

- 新增教練／助教，登記登入信箱；新帳號等待驗證，介紹預設不公開。
- 按季度、班級與教練篩選、預覽及批量更正考勤；缺勤／未打卡可人工補正，未來課次及停課不預填。
- 學員轉班，選擇保留歷史或映射移轉點名等相關記錄；保留收費與核款資料，防止表格同步改回原班。
- 編輯學員必要資料及管理員內部備註；舊版本表單不能覆蓋新資料。
- 查看帳號驗證、教練登記、班級和裝置活動；授予及撤銷管理員，保護本人與最後管理員，保留操作紀錄。
- 統一財務密碼管理資格，仍使用既有財務二次驗證。
- 解除季度封存後修正歷史資料與跨班點名；恢復為已結束，同步及招生不自動開啟。

季度、課程、商品、官網內容、媒體、訂單及收款帳戶沿用原管理入口；已核對其伺服器角色檢查。列表改為分頁完整讀取，避免人數增加後只顯示前 1,000 筆。

## 驗證與範圍

- 隔離版本：基準 `6cd70a0afd6c78d82c16cf819e7e75a0f70f5844`，檔案由 `super-admin-release-manifest.json` 明確列出。
- 273 項應用測試全部通過；7 組 PostgreSQL 相容環境驗證全部通過，包括 6 組管理 RPC 的權限、舊預覽、資料衝突、回滾與審計，以及 1 組實際 API 保存後的公開網站讀取驗證。
- 正式構建通過，產生 65 頁。TypeScript、修改檔案 ESLint、繁體中文和差異空白檢查通過。
- 本地完整後台與模擬 API 驗證手機／電腦入口、帳號管理、學員編輯和手機解除封存；新增助教、轉班、批量考勤也有瀏覽器流程證據。
- 測試沒有冒用正式管理員或教練帳號；真實帳號、正式資料連通、實體手機仍須上線後驗收。
- GPS、點名自動儲存、登入連續性及首頁／圖片的其他待發布變更不在本版中。扁扁教練的真實裝置問題仍需個別驗證，不能以本版帳號診斷功能替代。

## 發布順序

1. 取得本版正式發布授權後，從清單產生獨立版本；確認遠端基準未漂移，不把整個工作目錄直接提交。
2. 重新只讀核對正式 4 位管理員的驗證及撤權狀態，保存必要遷移前資料及函式定義；預檢數量是 2026-10-08 的快照。
3. 依序套用 6 個遷移：`20261008090000` 新增教練、`20261008100000` 批量考勤、`20261008110000` 轉班、`20261008120000` 帳號權限、`20261008130000` 學員資料、`20261008140000` 解除封存。
4. 核實 RPC／表權限和既有管理員解析正確後再切換應用。新的登入權限依賴 `resolve_account_role`；缺少函式會拒絕請求。
5. 驗證不同真實 admin 的管理入口、教練／學員的拒絕邊界、既有帳號登入與主要營運流程；需寫入的正式驗收須使用經批准的目標，不能為了測試修改真實核款或考勤。

## 失敗處理

遷移失敗則不發布應用，先定位原因。不要直接刪除新增審計表或逆向批量恢復角色。帳號權限遷移含舊角色修正和防撤權繞過觸發器；應用回退必須保留新的角色解析與撤權防護，不能無條件切回舊授權實作。新產生的營運資料應保留，按操作紀錄逐筆評估修正。

正式套用、發布和真實帳號驗收均尚未執行；目前沒有更改正式管理員權限。

使用者已明確要求先完成本地設計與驗證，再推送。本地操作能力與驗收見 `super-admin-local-guide-2026-10-08.md`；本文件的正式發布步驟屬於下一階段。
