# 请假方式切换与点名前置保存修复

教练点击请假时，如有未保存点名，先自动保存并重新读取，成功后打开请假窗口；失败时保留草稿并显示错误。保存期间禁止修改班级、课次和备注，阻止重复保存。

同一笔请假可由有权限的教练在自主训练与线下补课之间调整，不新建补课资格。数据库只允许经授权事务将该笔自主训练记录转为待选，再调用原有容量校验安排目标课次；失败则整笔回滚。学生、无关教练、已完成/已有到课记录、封存季度及额满等原有保护保留；最近7天回溯和季度范围未改变。

验证：338项测试通过，20项隔离Postgres检查通过，含双向切换、同一资格、满额回滚和原权限限制。修改文件ESLint、最终生产构建通过。WebKit实际组件以虚构学员验证A备注保存后打开B请假，失败保留草稿、成功重读后再打开；390px弹窗无横向溢出，说明及按钮可见。全库既存媒体测试lint问题未混入本次修复。

上线前已核对两项数据库函数与主分支基线哈希一致；迁移仅更新函数，没有替任何真实学员修改请假或点名。用户已明确要求修改后上传。
