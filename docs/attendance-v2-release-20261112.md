# 點名第二版正式整合

使用者於2026-11-12明確要求「好的，請你上傳！然後一定要適配好運網站」，授權本次整合、驗證及發布。

## 實際行為

- 教練原有課程點名入口預設顯示整期總表；可切換當堂點名。
- 桌面姓名欄固定、累計在姓名旁；預設只顯示截至今日的課次，可顯示未來課次。
- 手機採可展開的學生清單與課次格；點課次開啟底部面板，桌面則為側欄。
- 搜尋、全部／有請假／待點名／插班篩選，以及CSV匯出。
- 使用正式API提供的課程、學生、點名、補課與停課資料，不包含預覽示例或localStorage持久化。
- 未入班與停課不列入累計，未來課次禁止到課點名，仍可依法定的網站規則登記請假。
- 到課與已扣除操作即時儲存；只提交有變更的學員。備註按完成或儲存，切換課次前會先儲存。失敗保留草稿並提供重試；離開頁面有未儲存資料會提示。
- 請假、線下補課與自主訓練沿用現有對話框與後端權限、名額、課次及回溯限制。整堂停課留在當堂點名，避免在單人面板誤操作整班。
- 不新增或改寫正式點名資料、不修改API權限或資料庫結構。

## 與靜態預覽的適配

採網站既有視覺樣式及「已扣除」業務狀態，不新增示例的缺席狀態；補課完成由既有補課流程判定。顯示既有紀錄的最近更新時間，不偽造歷史修改紀錄。

## 驗證

- 完整npm run check成功：繁體中文、346項測試、全庫ESLint、生產構建。
- Chrome與WebKit使用實際React元件、隔離模擬API驗收。

- 1440px桌面與390px手機檢查，手機無橫向溢出；原生dialog提供鍵盤焦點限制與Escape關閉處理。
