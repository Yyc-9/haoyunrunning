## 帳號改為管理員登記

- 教練管理同時顯示已啟用、待首次登入、停用狀態，可按姓名、信箱查找；所有已登記信箱者應出現，不限 profiles.role。
- 移除認證碼生成、列表、複製、個人頁兌換入口；舊 API 明確回 410，不保留繞過入口。
- 以私有且只允許伺服器存取的管理員授權名單實現預先加入。既有 verification_email 可作管理員已登記來源，但不是一般人可編輯的授權證據。
- 已註冊且 auth.users.email_confirmed_at 非空、主信箱精確符合者，原子連結公開身份及更新 role；保留 admin，不降權、不覆寫姓名、密碼、帳號偏好。
- 未註冊者正常以登記信箱登入並通過一般信箱驗證後原子啟用，不再另輸入教練碼。不可僅依 user_metadata、前端傳入 email 或可編輯的 profiles.email 授權。
- 顯式停用要同步停用授權名單，避免下次登入被自動恢復。重啟用只限管理員。重複信箱／身份已被其他帳號持有時明確拒絕，絕不搶占。
- 未啟用者可顯示課程關聯，但不能被當成已登入教練、不能接受代班。後續可由管理員登記姓名、信箱、公開身份，不新增頂層管理分页。
- 正式數據遷移由主代理審核和執行；不得把私人信箱寫入可提交測試、文件或截圖。

## 教練工作台設計

目標：手機打開即可完成今天签到，桌面保留日曆效率。延續既有深青／白色系、Lucide 圖標與繁體中文，不引入新 UI 套件，不改首頁。

1. 簡短問候後，先顯示今日課程、待回覆代班，統計與學員列表後移。
2. 今日每堂顯示時間、班名、地點、本人角色、狀態。已開放者直接按「本人到課簽到」，成功顯示伺服器時間；無今日課顯示下一堂。
3. 手機預設今日／近期列表，可切換日曆查日期；不縮小月曆作唯一入口。每個觸控目標至少 44px。
4. 桌面今日清單加月曆，可點課堂開詳情。手機底部抽屜、桌面對話框／詳情面板；可關閉、有焦點管理和 Esc，表單字體至少 16px，安全區與鍵盤下可捲動，不被底導覽遮住。
5. 簽到、請假、代班三個任務依狀態露出，不堆疊全部表單。請假理由輸入不得因輪詢或 React 子組件重建失去焦點。
6. 顯示上次更新／重新整理；網路失敗不報成功；防連點；serverTime 校準 UI 時間且保留後端權威判定；焦點回到頁面時更新。

## 到課與代班規則

- 沿用 Asia/Taipei、課前 15 分鐘開放，課後 15 分鐘關閉；開始時間及以前 on_time，開始後 late。不得在客戶端自行補成功或冒用時間。
- 停課不簽到；未設定時間顯示待管理員補齊；逾時顯示「未簽到，待確認」，不等同缺席。此次不加 GPS、人臉、拍照或簽退門檻。
- 教練只對自己实际授課的課次簽到。兼任管理員的教練為自己課次签到仍是本人紀錄；替其他教練代登才標「管理員登記／補登」，留下操作者、時間、原因。
- 請假填原因，可邀請一位啟用教練，或不選人而送管理員安排。未生效前不悄悄免除原教練責任；狀態明確。
- 保留原定教練、实际授課教練。直接邀請由受邀者接受後生效；拒絕後可重選，或管理員處理。沿用既有管理員指派再確認流程，不悄悄改掉該流程。
- 已簽到／停課／已結束課次，拒絕一般請假或更換代班；逾時需要管理員有原因的異常處理。所有關鍵變更防 stale state／重複提交，不能移交後仍讓原教練簽到。
- 教練本人到課與學員出席核實是獨立紀錄，後者繼續與學員自行簽到雙重核對，不使用「替學員签到」文案。
- 代班獲得該堂必要的學員核實權限；不得擴展為整季、不相關學生資料權限。
- 課酬保持 pending_rate／待設定課酬，保留原定、实际授課、角色與人工更正的歷史，不產生薪資金額。
