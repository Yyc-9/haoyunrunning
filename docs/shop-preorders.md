# 商城預購

在商品編輯表單的「庫存」下方開啟「預購」，再按「儲存商品」。

- 預購商品可保留庫存 0；商店顯示「預購」，商品頁顯示「立即預購」。
- 預購不受現貨數量限制，也不扣現貨庫存。所有款式與規格共用此設定。
- 關閉預購後，恢復現貨庫存限制；庫存 0 顯示售完。
- 商品仍須上架並設定正數售價才能下單。預計到貨時間填於商品簡介。
- 訂單項目保留預購狀態及名稱標示。取消或付款逾時只回補當時實際扣除的現貨，後續修改商品設定不影響歷史訂單。

## 上線順序

1. 先套用 `supabase/migrations/20261020085639_shop_preorders.sql`，其前置依賴為既有商品規格 migration `20260905001751_shop_selectable_specifications.sql`。
2. 再發布應用程式。新版本商品查詢需要 `shop_products.is_preorder` 欄位。
3. 在正式後台選擇需要預購的商品，開啟並儲存。既有商品預設維持一般庫存模式。

同批更新統一商店列表、商品詳情、主圖、詳情圖與款式圖為 1:1 正方形。後台圖片輸出上限為 1280 × 1280 像素，前台完整顯示圖片，不放大裁邊。
