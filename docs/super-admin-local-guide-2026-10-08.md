# 本地超級管理員操作範圍

本次目標是先完成本地管理能力。相同超級管理員角色使用同一套入口與權限，日常內容與營運修改由後台完成；推送另行安排。

| 想修改的事項 | 後台入口 | 可完成的操作 |
| --- | --- | --- |
| 首頁、官網文案與圖片 | 內容中心 | 輪播圖片與順序、首頁文案、活動連結、訓練日程頁、團隊介紹、品牌聯絡、關於我們、學員見證、徽章、週年與商店視覺 |
| 季度與班級 | 季度管理 → 季度設定／課程資料 | 建立或複製季度、狀態、招生切換、班級內容、日期時間、地點、教練、容量與計價 |
| 教練與助教 | 教練管理 | 新增姓名與登入信箱、身份啟停、到課、請假、代班及單筆／批量人工考勤更正 |
| 學員基本資料 | 學員管理 → 資料與備註 | 姓名、電話、最佳成績、目標、管理員內部備註 |
| 學員轉班 | 季度管理 → 學員與統計 → 報名詳情 | 選目標班級、保留或移轉點名相關記錄；保留原付款資料 |
| 學員點名 | 學員管理 → 全班點名管理 | 管理跨班及已結束季度的點名，不要求管理員本人任課 |
| 商品 | 商城商品 | 名稱、介紹、圖片影片、規格、價格、庫存、上下架 |
| 收費與對帳 | 銀行對帳／收款帳戶 | 對帳與核款、財務密碼管理、增加收款帳戶及啟停 |
| 管理員權限／帳號問題 | 帳號與權限 | 授權、撤權；查詢驗證、教練身份、班級和裝置活動 |
| 修改封存季度 | 季度管理 → 季度設定 → 解除季度封存 | 填寫原因後恢復為已結束，再修改歷史資料；不自動重開招生或同步 |

電腦使用左側工作區；手機的季度、內容、商品、帳號權限與收款設定集中在「更多」。

## 操作規則

- 內容修改以「儲存並發布」保存；這裡指網站內容生效，不是程式碼部署。
- 批量考勤和轉班先預覽範圍、填寫原因，再確認；資料已被別人修改時須重新讀取。
- 新增教練後仍須完成該信箱的帳號驗證；新增身份不會自動把介紹公開。
- 封存保護、款項核對、最後管理員保護等規則對所有 admin 相同。
- 內部備註與登入信箱分開；收款帳戶可新增替代帳戶並停用舊帳戶，保留原交易關聯。
- 新增網站功能、改造頁面結構及改寫業務規則仍需開發；後台維護的是現有網站內容與營運資料。

## 本地驗收證據

既有 273 項隔離版本測試、6 組資料庫驗證與正式構建通過；另補第 7 組保存與讀取驗證，兩位管理員經實際權限解析及 API 在隔離資料庫完成內容、課程、商品、收款設定，公開網站讀取程式可取得保存結果。非管理員被拒絕，失敗不誤報成功。手機／電腦入口與新管理流程有本地瀏覽器驗證。

本地測試使用合成資料，不等於正式帳號與實體手機驗收；此階段未推送。
