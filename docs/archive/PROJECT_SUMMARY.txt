================================================================================
建议和最佳实践
================================================================================

代码方面:
  1. 保持 TypeScript strict mode
  2. 使用 useCallback 优化性能
  3. 避免在组件中进行复杂计算
  4. 使用 useMemo 缓存重复计算

架构方面:
  1. Provider 层次分明 (单一职责)
  2. 工具函数保持纯净 (无副作用)
  3. 组件是无状态的输入输出
  4. 状态集中管理在 Context

安全方面:
  1. 不存储敏感信息在 localStorage
  2. HttpOnly Cookie 存储 token
  3. 服务器端验证所有输入
  4. 使用 HTTPS 传输敏感数据

性能方面:
  1. 代码分割按路由进行
  2. 图片使用 Next.js Image 组件
  3. 搜索结果缓存 (useMemo)
  4. 虚拟滚动处理大列表
